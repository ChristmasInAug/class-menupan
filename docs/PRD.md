# PRD — 카페 메뉴판 (Excel 구동)

관련 문서: [CLAUDE.md](../CLAUDE.md) · [TRD.md](./TRD.md) · [원본 요구사항](./menu-project-requirement.md)

## 배경 및 목적

Excel 파일 하나로 메뉴판 화면을 구동한다. **Excel의 탭(시트) 1개 = 메뉴판 페이지 1개**로 매핑되고, **Excel을 수정하고 저장하면 화면이 즉시 갱신**된다.

이 프로젝트는 강의 앵커 예제다: "데이터(Excel)와 표현(템플릿)을 분리한다"는 원칙을 한 화면에서 보여준다. 점주는 코드를 건드리지 않고 Excel만으로 메뉴·가격·품절 상태·테마를 관리한다.

## 핵심 사용자 시나리오

1. 점주가 `menu.xlsx`를 Excel에서 열어 메뉴명/가격/설명/품절 여부를 수정한다.
2. 저장(Ctrl+S)한다.
3. 브라우저에 띄워 둔 메뉴판이 별도 조작 없이 자동으로 갱신된다.

> 값을 바꿔도 **저장 전까지는 반영되지 않는다** — 로컬 `.xlsx`는 저장 시점에만 디스크에 기록되기 때문이다. (OneDrive 자동저장 환경이면 거의 즉시 반영)

## 기능 요구사항

### 메뉴 시트 (커피 / 디저트 / 음료 …)

- 첫 행은 헤더, **시트 이름이 곧 페이지(탭) 이름**이 된다.
- 열 구성: 메뉴명, 가격, 설명, 품절, 카테고리.
- **가격**은 숫자만 입력(₩·콤마 금지). 통화 서식(`원`)은 화면 표시 단계에서 붙인다.
- **품절**은 `Y` 또는 빈칸. `Y`면 취소선 + 흐림 처리 + "품절" 라벨로 표시한다.
- 시트(탭)를 추가하면 메뉴판 페이지가 자동으로 늘어난다.
- `카테고리` 열로 한 페이지 안에서 소제목 그룹을 나눌 수 있다.

### `_설정` 시트 (언더스코어로 시작 → 페이지 목록에서 제외)

| 항목 | 값 | 설명 |
|---|---|---|
| 매장명 | 예: 빌런 커피 | 메뉴판 헤더에 표시 |
| 테마 | 예: cafe-dark | 코드 수정 없이 Excel에서 디자인 변경 |
| 자동전환초 | 예: 0 | 0이면 수동 전환, 양수면 그 초마다 페이지 자동 전환(디지털 사이니지용) |

## 비기능 요구사항

- **반영 시점**: Excel 저장(디스크 쓰기) 시점에만 화면에 반영된다. 이 제약을 사용자에게 명확히 고지한다.
- **갱신 지연**: 저장 시 발생하는 중복 파일 이벤트를 짧은 디바운스(수백 ms대)로 합쳐 한 번만 갱신한다. 사용자 체감상 "저장 후 거의 즉시" 갱신되어야 한다.
- **표시 전용**: 메뉴판은 읽기 전용 단방향 화면이다. 브라우저에서 데이터를 되돌려 쓰는 기능은 없다.
- **테마 전환 무중단**: 테마를 바꿔도 서버 재시작이나 코드 배포 없이 Excel 값 변경만으로 반영되어야 한다.

## 응용 아이디어 (강의 확장)

- 템플릿(CSS 또는 이미지 에셋)을 추가해 테마 종류를 늘린다(같은 데이터, 표현 계층만 교체).
- `카테고리` 열로 한 페이지 안에서 소제목 그룹을 나눈다.
- HTTP 공유 방식: 사내 파일서버에 `menu.xlsx`를 올리고 브라우저가 폴링(ETag)으로 갱신.
- 키오스크: 브라우저를 전체화면으로 띄우고 `자동전환초`로 페이지를 순환시킨다.
- 디바이스별(사이니지/태블릿/모바일) 최적화 레이아웃 제공(상세는 [TRD.md](./TRD.md) 하이브리드 테마 절 참조).

## Out of Scope (이번 단계)

- 코드 구현은 이 문서 단계의 범위가 아니다. 구현은 [CLAUDE.md](../CLAUDE.md)의 TDD 프로세스를 따라 별도로 진행한다.
- 다국어 지원, 결제 연동, 재고 관리 시스템 연동은 요구사항에 없으므로 명시적으로 제외한다.
- 메뉴판 화면에서의 데이터 편집(쓰기) 기능은 제외 — 편집은 Excel에서만 이루어진다.
